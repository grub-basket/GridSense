## GridSense 0.9.0

- **Grid config can now live in your vault.** Per-grid setup (columns, widths, sort, filters, views, formulas) is normally stored in the plugin's data.json, which only travels if you sync your .obsidian folder. Turn on **Store grid config in the vault** to mirror it into a normal vault file that syncs alongside your notes — and a newer copy arriving from another device is picked up live.
- **Deleting a row is now undoable.** Row deletes move the note into a GridSense trash folder inside your vault (browsable, restorable, ⌘Z brings it straight back) instead of going straight to Obsidian's trash. A new command, **Empty GridSense trash**, hands everything to Obsidian's trash when you're ready. Folder name is configurable.
- Wikilinks typed in cells are tidied automatically: extra brackets like `[[[[Note]]]]` collapse to `[[Note]]`, both while typing and on save.
