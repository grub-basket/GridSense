## GridSense 0.14.0

A big batch from a round of real-world use. Highlights:

**Grid**

- **Freeze panes**: pin the first N columns and/or rows while you scroll (▦ columns & views).
- **Hidden things are now obvious**: a red warning in the toolbar names how many columns are hidden and how many rows aren't shown, and opens the manager when clicked.
- **Set a column's width by typing it** — right-click the header → Set column width, or go back to automatic.
- Columns keep their order when you fill in values (they used to reshuffle), and new columns are always added at the end.
- Fill down/right no longer flickers — filled cells stay filled while Obsidian catches up.

**History**

- **Row, column and cell history**: right-click a row number, a column header or a cell to see just that item's edits, each with a one-click **restore**.

**Formulas**

- New formula columns: **COUNTIF, SUMIF, CONCAT, IF, IFS and AND**, built with a condition editor (=, ≠, >, <, ≥, ≤, contains, empty, not empty). CONCAT can join properties, file.basename/path/folder, and quoted literals.

**Import**

- **Import notes from a spreadsheet paste**: paste your cells, map columns to properties, preview, then create the notes — nothing is written until you say so, and the raw paste is saved as a CSV first in case you want to redo it.

**Files & notes**

- **.grid files**: save a folder's grid as a document (folder menu → Save as .grid file) and open it like any other file.
- The properties panel takeover can now be switched **per note** as well as globally, with commands for both.
- Many grid actions are now commands you can bind hotkeys to: fill down/right, find & replace, undo/redo, word wrap, add column, columns & views, history, recompile, import, empty trash.
