## GridSense 0.15.0

**Fixes**

- Links to notes that don't exist now look unresolved (faded, dashed) instead of like normal links.
- Fill down/right on many cells now locks the grid read-only, shows a progress notice saying so, keeps your scroll position, and repaints once at the end instead of flickering.
- Editing a cell no longer makes its row vanish from an active filter mid-edit — filtered rows stay put until you change the filter or refresh.
- The floating new-row bar no longer leaves a sliver of the last row showing underneath it.
- Column headers are now guaranteed to stay above frozen rows while scrolling.

**New**

- **Stacked filters** (⛃ filters): build up property conditions with all/any matching, like Bases — the quick filter box still narrows whatever they leave.
- The filter box has a clear (✕) button.
- **Bases Toolbox property tools** appear in the column header menu and columns manager when that plugin is installed: format doctor, property index, allowed-value and alias audits, fork/convert, duplicate finder, inline-field migration, rollups, metadata stamp.
- The properties switch button now names only the mode you'd switch to, and hides Obsidian's redundant "Properties" title while it's shown.
