## 0.20.0 — grab, rename and delete on every property row

- Each row in the GridSense property editor now ends with three buttons: a **grab handle**, a
  **pencil** and a **trash**.
- Drag the grab handle to reorder a property, or press **Alt+↑ / Alt+↓** to move the selected row.
  Reordering rewrites the frontmatter key order — YAML key order is the stored order — as a single
  undoable step, leaving every value untouched. Keys added by something else in the meantime keep
  their values and follow the known ones rather than being dropped.
- The pencil opens the property name for renaming; the trash removes the property, undoably.
