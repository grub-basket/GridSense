## 0.22.0 — open Stashpad notes in Stashpad

- New setting, **off by default**: when a grid row's note lives in a Stashpad folder, clicking it
  opens the note in **Stashpad's own view** — keeping its place in the parent/children tree — instead
  of the plain markdown editor.
- Cmd/Ctrl-click and middle-click do the same in a new tab.
- Only real Stashpad notes are redirected: a file needs a Stashpad `id`, so author files,
  attachments, and any note outside a Stashpad folder open exactly as before.
- Needs the Stashpad plugin, and says so once if you switch the setting on without it. GridSense
  doesn't otherwise depend on Stashpad — everything works with it absent.
