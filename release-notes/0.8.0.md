## GridSense 0.8.0

**Fixes**

- Columns no longer reshuffle when you fill in values — column order is stable, and newly added columns go to the end.
- Fill down/right no longer flickers: filled cells stay filled instead of blanking out and restoring while Obsidian re-indexes.
- Right-clicking a multi-cell selection keeps the selection (it used to collapse to one cell, which is why fill from the menu worked but the hotkey complained).
- Clicking inside a cell you're editing no longer kicks you out of edit mode.
- The floating new-row form can no longer cover the last data row.

**New**

- Internal links render as real links in cells, including aliases (`[[Note|shown text]]`), and cell editing offers note autocomplete after you type `[[`.
- Right-click a row number to delete that note (moved to trash, with a confirmation).
- Per-grid column width cap in ▦ columns & views.
- Property-type icons in the columns manager.
- A button above the note properties panel switches between GridSense's editor and Obsidian's, both ways, without a trip to settings.
