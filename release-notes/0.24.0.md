## 0.24.0 — faster workspace restore for open grids

- A grid left open in the workspace no longer blocks Obsidian from finishing its layout on startup.
  Previously the grid built its whole table synchronously while the workspace was restoring each tab,
  so a grid tab delayed the vault appearing ready by the grid's render time. The grid now loads its
  cached snapshot and then paints on the next tick, off that critical path, so the workspace finishes
  laying out first and the grid fills in immediately after. (The paint is scheduled with a timer
  rather than an animation frame, so a grid restored in a background tab still paints without waiting
  to be focused.)
