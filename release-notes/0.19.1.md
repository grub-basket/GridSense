## 0.19.1 — properties switch button fix

- Fixed the button that switches a note between the GridSense property editor and Obsidian's own
  panel. Recent Obsidian builds made the properties heading row a collapse control, and the button
  lived inside that row — so every click flipped the mode *and* collapsed the panel, hiding the very
  thing it had just switched to. The button now sits in its own row below the heading, and ignores
  the pointer events the heading acts on.
- Obsidian's collapse chevron now folds the GridSense editor too. Previously it only hid the native
  panel, which the takeover already hides, so the chevron appeared to do nothing.
- Obsidian's properties heading stays visible while the GridSense editor is in use, so a panel that
  was collapsed before switching can always be reopened.
