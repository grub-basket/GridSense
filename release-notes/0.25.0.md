## 0.25.0 — autocomplete in every text box that names a folder, note, tag, property or value

- **One shared suggester (`src/suggest.ts`).** The existing `ListSuggest` is extended into a single `AbstractInputSuggest`-based module used by every field below. Matching is case-insensitive and order-independent, with prefix matches ranked first; vault scans run lazily when a list first opens. An Enter-safe mode is used wherever Enter already commits or submits: a plain Enter keeps what was typed, and only arrowing into the list and then Enter picks a suggestion.
- **Grid cells suggest values** already used in that column across the vault. The list waits for a keystroke, so a fast Enter/Tab run through cells is never interrupted; with the list open, the first Escape closes it and a second cancels the edit. In a cell that already holds a list, only the item under the cursor is completed (`project, ur|, someday` → `project, urgent, someday`). The `[[` link completion in the cell editor now runs on the same module.
- **Draft rows and the add-row form** suggest values for each column. Fixed: in the add-row form, pressing Enter in an empty focused field filled in a suggestion instead of submitting.
- **Find & replace:** when the scope is a single column, Find and Replace with suggest that column's values.
- **Filters:** stacked filter values suggest the property's values (folders for `file.folder`); the column filter's condition value suggests the column's values, most common first.
- **Views and headings:** the save-view fields suggest existing view names (a plain Enter still saves exactly what was typed, so a new name is never overwritten by a similar existing one); the heading picker suggests the grid's headings.
- **Property editor (including the inline frontmatter takeover):** the key field suggests vault property names the note doesn't already have; value fields suggest values for that key, list-item aware; chip editing and "+ add" suggest values (or tags, for tag properties), leaving out items already in the list.
- **Formula builder:** the column name suggests this grid's properties, condition values suggest the property's values in the scanned folder, and the existing directory/property/heading fields move onto the shared module.
- **Importer:** helper-column default values suggest vault values for that property; property names also come from a vault-wide scan.
- **Settings:** the trash folder suggests folders and the config file path suggests `.json` files in the vault.
