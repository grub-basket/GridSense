## 0.23.0 — importer helper columns

- **Importer: helper columns.** The spreadsheet importer gained an **Add helper column** control.
  A helper column is an extra property that is not in the pasted data but gets seeded on every
  imported note — leave its value empty for a blank column you fill in later, or give it a default
  value applied to every note. This lets you paste a spreadsheet and come away with ready-to-use
  columns the source never had (a `notes` column to write into, a `status` starting at `todo`, and
  so on). A helper never overwrites a value that already came from the paste, so a helper named like
  a mapped column only fills the rows the paste left blank. Helper columns appear in the import
  preview in a muted style so they read as added rather than pasted.
- **Properties panel: quieter switching.** Switching a note between the GridSense property editor and
  Obsidian's own panel no longer shows a notification. The panel swaps visibly on the same click, so
  the toast was redundant.
