## 0.21.0 — edit list items in place

- In the GridSense property editor, each item of a list property (the chips) is now individually
  editable. **Click a chip** to edit that one item in place; **drag a chip** to reorder it within the
  list; the existing **×** still removes it.
- A dashed **"+ add"** at the end of each list appends a single item without retyping the whole
  comma-separated value.
- Every one of these is a single undoable step. Items are typed like the list they belong to, so a
  tag keeps its `#`-free form. Emptying an item's text removes it.
- Dragging a chip onto a *different* list property is ignored, so items can't accidentally jump
  between lists.
